# Progressive Disclosure Pattern

Don't dump everything at once. Each step: do first, summarize, confirm, then proceed.

## Core principles

For each step:
1. **Do** (search, discuss, act)
2. **Summarize** (structured result)
3. **Confirm** (ask user's view)
4. **Proceed** (only after confirmation)

## Transition between steps

At end of each step:
- One-sentence summary of step's outcome
- Ask user: "ready to move on?" or "anything to adjust?"
- Only proceed after explicit confirmation

Don't auto-skip steps. Even if user says "hurry up", keep each step's core output, just compress the discussion.

## Information density control

| Stage | Density | Form |
|---|---|---|
| Step 1 | Low | dialogue, 3 questions |
| Step 2 | Med-high | knowledge map (structured list) |
| Step 3 | Med | project decomposition (table) |
| Step 4 | Low | 3 actions (concise) |
| Step 5 | Med | weekly template |
| | High | full docs (research report + plan) |

## User-acceleration signals

Compress dialogue when user:
- Already gave a detailed learning goal
- Says "hurry" / "just give me the plan"
- Has clear project direction already

Even with acceleration, Step 2 (multi-source research) cannot be skipped — it's the core value.

## User-deceleration signals

Slow down when user:
- Says "I'm not sure" / "haven't decided"
- Goal keeps changing
- Asks many basic questions

In this case extend Step 1 to help them clarify direction.
